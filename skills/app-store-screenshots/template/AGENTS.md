# Screenshot project instructions

Before work on every request or resumed session, check `https://github.com/mweisberg21/app-store-screenshots` for updates. Use the installed `app-store-screenshots` skill and its `references/updates.md` procedure. If the skill is not available, obtain it from this team fork and read `skills/app-store-screenshots/references/updates.md` before continuing. Check the live repository even when this editor already runs.

Use `main` unless the user explicitly selected another branch or pinned version. Read `.screenshot-tool-source.json` and `HOW-TO-OPEN.md` when present. Download and apply available updates to the installed skill and this editor before screenshot work. Re-read the updated instructions. Do not silently use a stale copy when the check or update fails; report the problem and wait for the user's choice.

Back up before replacement. Preserve `app-store-screenshots.json`, customer images, fonts, briefs, notes, exports, and local code changes. Do not overwrite this project with a starter template. Merge project instruction files. Keep the included device frames and the local-only server controls.

After the update check succeeds, continue the requested work. For a first-time user, follow the skill's first-run guide. For a returning user, preserve the project and open the editor without repeating the full tutorial.
