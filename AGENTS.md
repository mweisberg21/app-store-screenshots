# Working with this repository

For a request to set up, open, or use the screenshot tool, read `START-HERE.md` and `skills/app-store-screenshots/SKILL.md`. For first use, follow `skills/app-store-screenshots/references/first-run.md`. Carry out the setup and teach one step at a time in plain language. Verify local access before claiming anything is installed on the user's computer.

For maintenance or code review, work on the requested change. Do not start the first-use walkthrough unless the user needs it. Preserve customer files, local original Apple frames, and existing work. The first-run guide describes platform checks; the template README describes developer tests.
